## 🚀 How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Abhaysoni09/Unfold.git
```

### 2. Navigate to the Project

```bash
cd Unfold
```

### 3. Install Dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd ../frontend
npm install
```

---

### 4. Configure Environment Variables

Create a `.env` file inside the **backend** folder.

Example:

```env
PORT=3000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

CLIENT_URL=http://localhost:5173
```

> Add any other required environment variables (Cloudinary, Stripe, etc.) if your project uses them.

---

### 5. Start the Backend

```bash
cd backend
npm run dev
```

---

### 6. Start the Frontend

```bash
cd frontend
npm run dev
```

---

### 7. Open in Browser

```
http://localhost:5173
```
